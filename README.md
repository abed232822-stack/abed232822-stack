## 🚀 Featured Projects

### 🚕 Smart Taxi — *Ride-hailing app (client project)*
* One Flutter app with two roles, **customer** and **driver**, in Arabic (RTL) and English. Live on [Google Play](https://play.google.com/store/apps/details?id=com.ma.smarttaxi); iOS coming soon.
* Customers pick pickup/drop-off on a map, see a price per vehicle type, follow the driver live and pay in cash. Drivers go online, take ride offers in real time, run the trip and track earnings in a monthly wallet.
* Built against the client's REST API and **Socket.IO** events. Cuts paid Google Routes requests by matching GPS fixes to the route already fetched, and keeps users signed in when offline (signs out only on an explicit 401).
* **Tech Stack:** Flutter, Dart, Cubit, Dio, Socket.IO, Google Maps, Firebase Cloud Messaging, GetIt.

### 🏆 Star Liga — *Football league management app*
* Arabic RTL app for running local tournaments: fixtures and match timelines, group and knockout standings, top scorers and card stats, and a club registration flow with squad-rule validation.
* Built against a real league's API. [Source code](https://github.com/abed232822-stack/StarLiga)
* **Tech Stack:** Flutter, Dart, Bloc, Dio, GetIt.

### 🧪 Mini API Client — *Postman-style desktop client*
* REST API client with nested collections, key–value params and headers, a syntax-highlighted JSON editor, pre-send validation and a response viewer. All data is stored locally. Desktop-first, responsive down to mobile.
* [Source code](https://github.com/abed232822-stack/Mini-Api-Client)
* **Tech Stack:** Flutter, Dart, Bloc, Hive, Dio.

### 🛒 E-commerce API — *Laravel REST backend*
* Token auth (Sanctum), products and categories, cart with stock checks, orders, and **Stripe** payments confirmed through a webhook. Service layer with DB transactions, authorization policies, roles & permissions, and rate limiting.
* [Source code](https://github.com/abed232822-stack/E-commerce-Api) · [Postman docs](https://documenter.getpostman.com/view/47220640/2sBXqFPNij)
* **Tech Stack:** Laravel, PHP, MySQL, Stripe, Sanctum.

### 🏬 E-commerce (Full-stack) — *Laravel web app*
* My first Laravel project, built to learn the framework: customer, seller and admin roles, an approval flow for products and orders, a balance-based checkout and database notifications.
* [Source code](https://github.com/abed232822-stack/Simple-Ecommerce)
* **Tech Stack:** Laravel, PHP, MySQL, Blade, Tailwind CSS.
